# **App Name**: KanFlow

## Core Features:

- Board Display: Visualize tasks organized into configurable columns such as 'To Do', 'In Progress', and 'Done'.
- Task Creation & Editing: Easily add new tasks with titles and descriptions, and modify existing task details.
- Task Movement: Drag and drop tasks between different columns to reflect their current status.
- Task Deletion: Remove completed or unnecessary tasks from the board.
- AI Sub-task Suggester: An AI tool that suggests relevant sub-tasks or action items based on a newly created main task's description to aid in breaking down complex work.
- Task Persistence: Save all tasks and their states so that board configurations and task progress are preserved across sessions.

## Style Guidelines:

- Color scheme: Light mode, providing clarity and focus for a productivity application. The primary color is a deep, thoughtful blue-green (RGB: 31, 121, 157; Hex: #1F799D), evoking organization and flow. The background is a very light, almost white, desaturated variant of the primary hue (RGB: 236, 241, 242; Hex: #ECF1F2). The accent color is a vibrant green (RGB: 56, 237, 178; Hex: #38EDAB), used for positive actions and highlighting completion.
- All text will use 'Inter', a grotesque-style sans-serif font, chosen for its modern, clean, and objective appearance, ensuring high readability for task titles and descriptions across various screen sizes.
- Employ simple, outline-based icons for key actions like adding, editing, and deleting tasks. Icons should be easily recognizable and contribute to a clutter-free interface.
- The layout will feature a multi-columnar structure with clear visual separation for each Kanban stage. Tasks within columns will be presented as distinct cards. The design will be responsive to adapt smoothly across desktop and mobile devices.
- Subtle, fluid animations will be used for interactions such as dragging and dropping tasks between columns, providing visual feedback and enhancing the user experience without being distracting.
